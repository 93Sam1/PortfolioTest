Collecte Automatisée de Données Web — Scraping Blue Buffalo

📅 Semestre 3 — 2025/2026🎓 SAÉ 3.01⏱️ ~25h encadrées + travail personnelSamuel ROCHEMONT
🔍 Agrandir

Cadre du projet & Objectifs

Le web est une mine de données en accès libre. En tant que consultant décisionnel, l'enjeu était de concevoir une solution capable de collecter, structurer et qualifier des données produits externes pour alimenter un entrepôt de données. Ce projet de groupe nous a confié la marque Blue Buffalo (alimentation animale). Objectif : construire un scraper robuste sous Google Colab avec Playwright pour extraire les fiches produits chiens et chats.

Étapes de réalisation

Analyse de la structure du site & choix technologiques

Blue Buffalo présente un contenu dynamique généré en JavaScript — impossible à extraire avec une simple requête HTTP. Nous avons choisi Playwright (simulateur de navigateur) plutôt que BeautifulSoup pour gérer ce rendu dynamique. Étude des balises HTML cibles : nom, prix, ingrédients, poids, image, URL produit.

Développement du scraper

Navigation automatisée vers les pages Chiens et Chats. Extraction des balises HTML cibles pour chaque fiche produit. Nettoyage des données brutes : strip() et replace() pour retirer les devises, normaliser les poids, supprimer les caractères parasites. Gestion des cas d'erreur (produit sans prix, page manquante).

Structuration & export CSV

Création d'un DataFrame Pandas respectant le schéma imposé au groupe : colonnes brand, species, sku, name, price, rating, weight, ingredients, image_url. Export CSV propre, directement exploitable pour l'alimentation du datawarehouse du projet global.

Ce que j'en retire

Le web scraping : entre technique et éthique

Au-delà du code, ce projet a soulevé des questions sur les limites du scraping : respect du robots.txt, fréquence des requêtes pour ne pas surcharger le serveur, utilisation des données dans un cadre légal. Ces considérations font partie intégrante du métier.

💡 Ce que j'ai retenu

Playwright est bien plus puissant que les approches statiques pour les sites modernes — mais aussi bien plus exigeant. La vraie difficulté n'était pas d'extraire un produit, mais de rendre le scraper fiable sur 300 produits avec des structures HTML variables. La robustesse, pas la vitesse, est le vrai critère de qualité d'un scraper.

Ce que ça m'apporte en entreprise

Un pipeline de scraping robuste est un actif réutilisable pour n'importe quelle entreprise cherchant à monitorer ses concurrents, alimenter un catalogue produits ou automatiser une veille tarifaire. La maîtrise de Playwright + Pandas + Google Colab représente un stack moderne directement employable en data engineering ou consulting.
